# Add a worklog advisor agent

Add a worklog advisor agent with the knowledge necessary to advise on worklog operations.
The main agent may consult the advisor for instructions before performing an operation related to worklog.

The advisor is primarily a temporary measure until t0006 and t0007 are implemented,
but this task is independent of t0007 and the advisor MAY remain afterward.

Complete when the advisor's role, consultation contract, and required knowledge are specified,
and the advisor is available to the main agent.
