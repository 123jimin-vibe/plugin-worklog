# Add a tag database

Add the tag database missing from worklog v0.2.

## Proposed scope (NEEDS APPROVAL)

Define the database's canonical location and format, tag identity and normalization rules, entry metadata and lifecycle, and behavior for unknown or unused tags.
Define how worklog entities and tools use it without turning a tool-specific index into project authority.
Preserve compatibility with existing worklogs whose entities already contain tags without a tag database.

Complete when the governing specs define the tag database and its compatibility behavior, required artifacts and tool behavior are implemented, and representative existing and new worklogs are verified.
