# Note entities

## Related entities

- s0002 defines common entity rules.
- s0012 defines agent modes and entity policy.
- n0001 guides writing.

## Principles

- A note preserves reusable project guidance.

## Inherent properties

### Identity

- ID prefix: `n`.

### Authority

- A note does not establish authoritative project behavior.

## Desirable properties

### Creation

- Create a note for guidance that is not verifiable as project behavior, such as conventions, recurring mistakes, or working advice.

### Maintenance

- When a note's guidance becomes authoritative, move its content to a spec.
- Remove a note when one or more specs completely replace it.
